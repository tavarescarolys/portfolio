# Portfólio — Carolys Tavares

Site estático (HTML, CSS e JavaScript puro) do portfólio de branding da Carolys Tavares.

## Estrutura

- `index.html`, `sobre.html`, `servicos.html`, `portfolio.html`, `contato.html`, `recebido.html`: páginas principais
- `cases/`: uma página por projeto
- `assets/`: imagens, vídeos, fontes e `js/main.js`
- `styles.css`: estilos do site

## Rodar localmente

```bash
python3 -m http.server 8000
```

Depois abra http://localhost:8000.

## Publicação

Hospedado no GitHub Pages, direto da branch `main` (raiz do repositório).
